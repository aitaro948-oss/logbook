# logbook

個人用の記録アプリ置き場。各アプリは単一HTMLで、iPhoneのホーム画面から起動して使う。
公開先: GitHub Pages（`https://aitaro948-oss.github.io/logbook/`）

## 構成

```
logbook/
├── index.html      アプリ一覧ページ（サイトのトップ）
├── README.md       このファイル（運用手順）
└── gym/
    └── index.html  筋トレ記録アプリ
```

## アプリを更新する（コードを直したとき）

1. **先にアプリ内で「バックアップを保存」を実行する**（記録は端末内にあるため）
2. GitHubで対象フォルダ（例：`gym`）をクリックして中に入る
3. 「Add file」→「Upload files」で新しい `index.html` をドラッグ＆ドロップ
4. パス表示が `gym/index.html` になっていることを確認して「Commit changes」
5. 1〜2分待ち、iPhoneでアプリを上スワイプで完全終了 → アイコンから開き直す

※ リポジトリのトップでアップロードするとルートに置かれてしまうので注意。

## アプリを新しく追加する

1. PCで短い英小文字のフォルダ（例：`kakeibo`）を作り、中に `index.html` を入れる
2. リポジトリのトップで「Add file」→「Upload files」→ **フォルダごと**ドラッグ＆ドロップ
3. ルートの `index.html` を開き、鉛筆アイコンで編集してリンクを1行追加

```html
<a href="./kakeibo/">家計簿<span>日々の支出を記録</span></a>
```

`./kakeibo/` がフォルダ名、その後ろがカード名、`<span>` が説明文。他は触らない。

4. iPhoneのSafariで `https://<ユーザー名>.github.io/logbook/kakeibo/` を開き、
   共有ボタン →「ホーム画面に追加」

## 運用ルール

- **フォルダ名は変えない。** URLが変わるとホーム画面アイコンと端末内データの参照先が変わる
- **フォルダ名に日付やバージョンを入れない。** ローカル管理用の名前とは分ける
- **localStorageのキーはアプリごとに固有名にする**（`gymlog.v1`、`kakeibo.v1` など）。
  `<ユーザー名>.github.io` 配下は全アプリが同一オリジン扱いになり、保存領域を共有するため
- **ホーム画面のアイコンを削除しない。** 端末内の記録ごと消える可能性がある。
  消す必要があるときは必ず先にバックアップを取る
- 記録データは端末内が正本。バックアップはアプリの「保存」からOneDriveへ

## 各アプリのメモ

### gym（筋トレ記録）

- localStorageキー: `gymlog.v1`
- 入力・分析・体重記録をアプリ内で完結。Excel連携なし（CSV書き出しのみ）
- 最終バックアップから30日経つとホーム画面に警告バナーが出る
