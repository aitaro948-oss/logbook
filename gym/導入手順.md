# 筋トレ記録アプリ 導入手順

## 1. 公開する（GitHub Pages・無料・約5分）
1. GitHubで新しいリポジトリを作る（例：`gym-log`、Private でも可）
2. `index.html` をアップロードする
3. Settings → Pages → Source を「Deploy from a branch」、Branch を `main` / `/(root)` にして Save
4. 1〜2分後に表示されるURL（`https://<ユーザー名>.github.io/gym-log/`）をiPhoneのSafariで開く

※ Privateリポジトリの場合、Pagesの公開には有料プランが必要なことがあります。その場合はPublicにするか、Netlify Drop（netlify.com/drop）に index.html をドラッグしても同じことができます。

## 2. iPhoneのホーム画面に置く
1. SafariでアプリのURLを開く
2. 共有ボタン →「ホーム画面に追加」
3. 以後はホーム画面のアイコンから起動（全画面のアプリとして動く）

**必ずホーム画面から起動すること。** Safariのタブで開いた場合と、ホーム画面から開いた場合で保存場所が別になります。

## 3. ジムでの使い方
- 「種目を選ぶ」→ 種目をタップ（あいうえお順・上部に最近やった種目）
- 前回のセットと自己ベストが表示され、重量・回数は前回のトップセットが初期値
- 重量は ±2.5 / ±0.5、回数は ±1 のボタン。数字をタップすれば直接入力も可
- 「セットを追加」を押すごとに1セット記録。同じ値のまま連続で押せば同重量のセットが積み上がる
- 自重種目は「自重」にチェック（チンニング等は自動でチェックが入る）

## 4. Excelへの反映（週1回程度、PCで）
1. アプリの「書き出し」タブを開く
2. 「A〜C列用をコピー」→ 01_入力フォームの最終行の次の空行のA列に「値のみ貼り付け」
3. 「E〜G列用をコピー」→ 同じ行のE列に「値のみ貼り付け」
4. 「貼り付け済みにする」を押す（次回は新しい記録だけが対象になる）

iPhoneからPCへのコピー内容の受け渡しは、ユニバーサルクリップボード（同じApple ID・Mac）か、メモアプリ経由が楽です。

## 5. 種目の追加
- アプリの「種目」タブで追加できる
- **Excelの02_種目マスターにも同じ名前で追加する**（集計・グラフに必要）

## 6. データの置き場所と注意
- 記録はiPhoneの中（このアプリ専用の保存領域）に保存される
- Excelに貼り付け済みの記録はExcelが正本。アプリ側はいつ消えても困らない状態を保つ
- 念のため月1回「全データを保存（JSON）」でバックアップ。iPhone機種変更時もこれで引き継げる
- 初期状態として、Excel（V3、7/27まで230セット）の記録を「貼り付け済み」として内蔵している
